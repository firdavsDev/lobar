# Rayxon — project guide for Claude

Uzbek chibi desktop pet for macOS. Swift 6 (strict concurrency), AppKit + SwiftUI, SwiftPM only (no .xcodeproj).
Repo: github.com/firdavsDev/rayxon. User communicates in Uzbek/English; UI strings are Uzbek (Latin).

## Commands
- `swift test` — 100+ unit tests (Swift Testing). Must stay green.
- `scripts/run.sh` — debug build → `dist/Rayxon.app` → relaunch. `scripts/run.sh --install` → release → `/Applications/Rayxon.app`.
- `scripts/bundle.sh [debug|release]` — build the .app (SwiftPM resource bundle copied inside).
- `scripts/sprites/build_all.sh` — regenerate every sprite strip from `art/<outfit>/*.jpg|png` + `manifest.json`.
- `scripts/release.sh VERSION` — signed/notarized DMG (needs Developer ID + notary profile; see README).
- Logs: `log stream --predicate 'subsystem == "dev.davronbek.rayxon"' --level debug`.

## Debug hooks (env vars on launch)
`RAYXON_DEBUG_DROP_Y=800` drop from height · `RAYXON_DEBUG_SAY="..."` speak on launch ·
`RAYXON_DEBUG_EVENT=rain|snow|birthday` fire an event · `RAYXON_DEBUG_SHOT=/dir` capture settings/tasks windows to PNG.

## Architecture (Sources/Rayxon)
- `App/AppDelegate.swift` — composition root; wires every service, menu actions, pet events → lines/voice.
- `Pet/` — `PetController` (30 Hz tick, state machine: idle/walk/fall/drag/sleep/activity/hiding/chasing/fetching),
  `Physics` (pure), `JumpPlanner`, `ShakeDetector`, `BehaviorPlanner`, `SpriteAnimator`/`FrameClock`, `PetWindow` (2× tall, sprite at bottom).
- `Surfaces/` — `WindowSurfaceProvider` polls `CGWindowListCopyWindowInfo` (no permissions; never read window names).
- `Chat/` — `LLMProvider` + Gemini/Claude/OpenAI, `Persona` (system prompt), `PhraseBook` (tone-keyed Uzbek lines),
  `Mood`, `Relationship`, `MemoryStore`, `ChatSession`, `LaughLimiter`, `ModelCatalog`.
- `Voice/` — Edge TTS via `uv tool run edge-tts` (`EdgeTTSCLIEngine`), `VoiceService`, `AudioPlayer`, `SoundFX`.
- `Wellness/` — reminders, Pomodoro, `RoutineEngine` (day rhythm, idle/away), `WellnessService` (1 Hz).
- `Fun/` — weather (Open-Meteo), `AppWatcher`, `GitWatcher`, `BreadDrop`, `CatVisitor`, `FloorProp`, `Games`, `PeerService`, `Props`.
- `Settings/`, `Tasks/`, `Stats/`, `Bubble/`, `Menu/` — UI. Settings = custom sidebar + grouped Forms.

## Conventions
- All AppKit/SwiftUI state is `@MainActor`; background work returns `Sendable` values. Timers use `MainActor.assumeIsolated`.
- TDD for pure modules (Physics, planners, parsers, stores, phrase/mood logic). UI is verified by running the app.
- Every spoken line goes through `AppDelegate.sayAndSpeak` (sleep gate + laugh limiter). New events: add a `PhraseBook.Event`
  with sulky/sassy/sweet pools, then wire in `AppDelegate`.
- Persona must stay a living character, not an assistant: short, emotional, teasing, Uzbek Latin, laughs rare.
- Sprites: 256×256 cells, feet baseline y=232, horizontal strips, `manifest.json` generated by `scripts/sprites/manifest.py`.
  Outfits appear in the menu only if `reference.jpg` exists in their folder. After slicing, ALWAYS render a grey contact
  sheet and look at it (user expects visual checks).
- Art comes from the user's Gemini web chat "Uzbek Chibi Desktop Pet Design" (Chrome). Quota: ~3 images then cooldown.
  Downloads may sit as `~/Downloads/.com.google.Chrome.*` temp files (complete JPEGs). Restate the outfit in every prompt.
- Never add AI attribution to commits. Commit only when the user asks.
